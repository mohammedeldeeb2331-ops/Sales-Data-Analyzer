# Sales Data Analyzer 📊

A Python project for analyzing sales data using Pandas and Matplotlib.

## 🚀 Project Overview

Sales Data Analyzer is a data analysis project that processes sales records, calculates revenue and profit, analyzes product and category performance, and visualizes monthly sales trends.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib

## ✨ Features

- Load sales data from CSV files.
- Inspect and validate data.
- Calculate total revenue, costs, and profit.
- Analyze sales by product.
- Analyze sales and profit by category.
- Calculate Profit Margin for each category.
- Analyze monthly sales.
- Visualize results using charts.

## 📁 Project Files

- `Sales_Data_Analyzer.py` — Main Python script.
- `sales.csv` — Input sales dataset.
- `requirements.txt` — Project dependencies.

## ⚙️ Installation

Install the required libraries:

```bash
python -m pip install -r requirements.txt
```

## ▶️ How to Run

Make sure `sales.csv` is in the same folder as the Python script.

Run:

```bash
python Sales_Data_Analyzer.py
```
